How to format links

Use the following formatting guidelines to white-/blacklist links properly.

Note: if the group is as a blacklist, the allowed and blocked work in reverse.

Just domain

Matches all links with that domain or specific sub domain ignoring the path.

Ending with /

Matches exact domain (or sub domain) with no or exact path.

Ending with a specific path or /*

Matches domain (or sub domain) and path.

Special channels

Use this module to create media only, emoji only, etc. channels.

  • Start by adding a condition.
  • Select at least one channel this condition should be active in by clicking on the hashtag.
  • Click on the box which says "Only ..." to set which content types should be allowed in the just selected channels.
  • The actions of a condition will be executed, if a message includes a not-selected content type.
